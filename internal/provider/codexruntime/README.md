# Qualified Codex runtime bridge

This package treats Codex as an external-agent runtime. The primary path is the
Codex App Server v2 JSON-RPC protocol generated by Codex CLI `0.145.0`. The
runtime binary and generated protocol are digest-pinned.

The App Server path permits only initialization, ephemeral thread creation,
one turn, interruption, typed turn/item/token notifications, and the pinned
experimental dynamic-tool request flow. It uses managed stdio, a fixed
workspace, an explicit restricted read-only sandbox, `untrusted` approvals,
invocation-scoped credentials, and an attested connected route. Only COH
broker-owned dynamic tools can execute. Native command, file-change, MCP/app,
web, skill, user-input, mutation, reroute, and unknown requests fail closed.

`codex exec` is a separately qualified and explicitly selected batch fallback.
It uses fixed arguments, cwd, ephemeral JSONL, strict/ignored user config,
ignored execution rules, explicitly disabled web search and native
shell/unified-exec/multi-agent/tool-suggestion features, a read-only sandbox,
bounded stdin/stdout/stderr/time, optional strict output schema, empty
caller-supplied environment, and an invocation-scoped credential channel
supplied by the managed runner. It accepts bounded progress agent messages and
returns only the last agent message while denying every native tool event. It
never resumes sessions, adds
directories or images, selects local providers/profiles, uses dangerous flags,
or receives an automatic failover from App Server. Batch requests with tools
are reported as unsupported because the CLI JSONL surface cannot prove broker
mediation; the bridge does not weaken the broker-only boundary to add them.

This implementation is the COH-E07-06 / CYB-61 delivery for FR-036 and FR-039.
Runtime failures return typed, redacted errors with a digest of the bounded raw
protocol trace when a trace exists. Tool calls and broker results are preserved
as correlated provider-contract items, including broker denials.

References: [Codex App Server](https://developers.openai.com/codex/app-server/),
[Codex SDK](https://developers.openai.com/codex/sdk/), and
[Codex non-interactive mode](https://developers.openai.com/codex/noninteractive/).
